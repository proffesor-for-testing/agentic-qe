# v3.13.10 Release Notes

**Release Date:** 2026-08-06

## Highlights

This patch restores trustworthy pattern consolidation and export behavior,
preserves learning thresholds across repeated initialization, and adds a
resilient off-main-thread path for larger PageRank workloads.

## Added

- Large weighted PageRank computations can run asynchronously in a worker
  thread, with deterministic TypeScript behavior retained as the fallback.
- AQE can use RuVector's native weighted PageRank contract if the upstream
  `@ruvector/solver` package becomes available in the future.
- Explicit pattern promotion now follows the same persistence, audit, and
  event path used by automatic learning.

## Fixed

- `aqe learning consolidate` reads the complete stored pattern view and now
  performs the promotions it reports. Dry runs remain non-mutating, and write
  failures are disclosed per pattern.
- Monthly aggregate reinforcement now records every observed use in the audit
  trail and evaluates promotion after updating the stored counters. The
  consolidate output also surfaces and enforces the 60% confidence gate.
- `aqe learning export` and `export-full` retain real success counts, success
  rates, quality scores, and memory tiers instead of exporting an indexed
  subset with stale metadata.
- `aqe init` preserves operator-selected `learning.qualityThreshold` and
  `learning.promotionThreshold` values.
- `aqe upgrade` no longer treats an unpublished RuVector solver binding as an
  installable package or strict-mode failure.
- RuVector solver documentation now reflects the current weighted iterative
  implementation instead of claiming an O(log n) solver.

## Changed

- The development-only Ruflo goal UI lock now resolves React Router 7. This
  snapshot is not part of AQE's published runtime dependency surface.

## Upgrade notes

No database migration is required. Existing learning thresholds and pattern
data are preserved. Native RuVector solver support remains optional; AQE works
without that unpublished package.
