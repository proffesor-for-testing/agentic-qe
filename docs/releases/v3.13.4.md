# v3.13.4 Release Notes

**Release Date:** 2026-08-02

## Highlights

Codex users now receive a complete, upgradeable Agentic QE workflow: curated
research, planning, testing, review, and optional Ruflo guidance backed by
installed-hook, skill, package, and MCP-registration verification.

## Added

- Three Codex-native workflows:
  - evidence-first technical research;
  - dependency-aware implementation planning;
  - optional Ruflo development-time orchestration guidance.
- Full `aqe platform verify codex` coverage for MCP configuration, generated
  instructions, lifecycle hooks, adapters, runtimes, and required skills.
- `npm run verify:codex-package`, which checks the real npm package inventory
  and detects missing Codex assets, Ruflo runtime leakage, and generated
  guidance that names unregistered MCP tools.

## Fixed

- `aqe init --with-codex --no-mcp` no longer writes a Codex MCP entry.
- Upgrading an existing Codex installation refreshes AQE's MCP tables without
  removing unrelated TOML configuration.
- Generated AQE instructions update inside explicit ownership markers while
  preserving project-authored `AGENTS.md` content.
- Custom hook groups survive upgrades, and repeated hook installation remains
  idempotent.
- A malformed hooks file no longer prevents skills from being installed or
  obscures the successful installation of other components.

## Changed

- Codex skill installation now uses an explicit curated manifest rather than
  discovering directories by prefix.
- Installer results report MCP, rules, hooks, and skills independently.
- Removed the unused duplicate init command implementation so one active option
  and help surface remains.

## Upgrade notes

Run the normal upgrade and verify the resulting Codex surface:

```bash
npx agentic-qe init --auto --upgrade --with-codex
npx agentic-qe platform verify codex
```

Existing project-owned TOML, `AGENTS.md` content, and custom hook groups are
preserved. Ruflo remains optional and is not added as a runtime dependency. To
install its Codex guidance and lifecycle integration, opt in explicitly:

```bash
npx agentic-qe init --auto --upgrade --with-codex --with-ruflo
```
