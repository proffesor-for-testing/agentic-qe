# v3.15.3 Release Notes

**Release Date:** 2026-10-11

## Highlights

A bug-fix release. AQE hooks work on Windows again. Several hangs, data-safety
and correctness bugs are fixed, mostly found while testing the
`agentic-qe-fleet` plugin end to end and in the October review batch.

## Fixed

- **AQE hooks run on Windows again.** On Windows, hooks generated by
  `aqe init` silently did nothing when agentic-qe was installed globally,
  because Node refuses to start `aqe.cmd` without a shell. Hooks now run the
  installed AQE bundle directly with Node. That works for npm, pnpm and
  yarn v1 global installs; Volta users can set `AQE_HOOK_BUNDLE`. Re-run
  `aqe init` to refresh existing hooks. This was verified with a simulated
  Windows environment, not yet on a real Windows machine ([#872]).
- **Hook and daemon files can't be redirected.** The hook, brain-checkpoint
  and daemon scripts no longer follow symbolic links when writing into
  `.agentic-qe/` (#872 hardening).
- **No more hangs on stalled servers.** These now time out instead of
  waiting forever when a server sends headers and then stalls:
  - LLM providers (including slow but healthy streams, which keep
    working) ([#889]);
  - Ollama embeddings ([#885]);
  - the Ollama and OpenRouter consensus providers ([#961]).
- **`RateLimiter.wait()` no longer hangs** when a request can never fit the
  bucket ([#905]).
- **Git refs are validated.** A commit reference that looks like a git option
  (for example `--output=…`) is rejected instead of being passed to git.
  Refs such as `@{-1}` and `HEAD^!` now work correctly ([#960]).
- **Test retries target exactly the right test.** Retried test names and paths
  are escaped and anchored for Jest, Vitest and Mocha. Names that start with
  `-` work, and Jest 30's renamed path option is used ([#909]).
- **`aqe test generate` writes every generated test**, not just the first
  10. Generated tests never land outside your project, and existing test
  files are kept unless you pass `--force` ([#936]).
- **Session journal is crash-safe.** A partial write is completed, not
  duplicated. If the disk stays full, the oldest buffered entries are dropped,
  and a gap marker keeps the session resumable ([#910]).
- **Fresh projects no longer log an RVF error.** Without an embedder you get
  one clear warning that explains how to enable vector search, and dream
  "apply" succeeds while the vector index is pending. The provenance check
  that protects existing indexes is unchanged ([#852]).
- **Cognitive complexity follows the SonarSource rules.** `else if` and
  nesting are no longer double-counted, and keywords in comments or strings
  are ignored ([#907]).
- Cargo test categories no longer overlap ([#906]). The git analyzer includes
  files from a repository's initial commit ([#874]). Optional native modules
  with a missing platform binary now degrade with a clear reason ([#858]).
- Hardening: costs, counters and caches are safe with keys such as
  `constructor` or `__proto__`. Embedding cache keys can't collide. Cached
  state deltas are JSON-safe ([#914]).

## Changed

- **Cognitive complexity scores are much lower.** Expect a one-time drop in
  stored reports and trends after upgrading ([#907]).
- **`aqe test generate` no longer overwrites existing test files.** Pass
  `--force` to overwrite them ([#936]).
- **`saveResults` on MCP domain tools.** The 11 tools that save results under
  `.agentic-qe/results/` accept `saveResults: false`. They also return
  `resultsSaved`, `resultsNote` and `savedFiles`, which is now always an
  array ([#925], [#933]). `aqe test generate --no-save` prints the tests
  instead of writing them.
- `goap-status` rejects unknown status filters, including the empty string
  (#894, from the October batch).
- Dependency updates (lockfile only, dev dependencies) ([#938]).
