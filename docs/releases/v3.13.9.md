# v3.13.9 Release Notes

**Release Date:** 2026-08-04

## Highlights

This patch refreshes the remaining Ruflo development-tool dependency snapshots
and is expected to close roughly 117 of the 119 Dependabot alerts open before
the change. AQE's published runtime dependency surface is unchanged.

## Security

- Six npm and pnpm locks now resolve patched versions of vulnerable archive,
  image, HTTP, telemetry, serialization, glob, and routing dependencies.
- Targeted overrides cover `adm-zip`, `sharp`, OpenTelemetry, `uuid`, `thrift`,
  `cookie`, and `picomatch` where upstream ranges otherwise retained vulnerable
  transitives.
- The unused v3 `semantic-release` dependency and its bundled npm toolchain were
  removed.
- React Router remains on the patched 6.30.4 release line. Two medium alerts
  require a 7.x migration, but the proposed 7.18 line currently carries a
  high-severity RSC-mode CSRF advisory and is not a safe substitution.

## Upgrade notes

No AQE API, CLI, database, or configuration migration is required. Ruflo stays
development-time-only and is not a shipped AQE runtime dependency.
