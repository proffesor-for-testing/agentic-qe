# v3.13.12 Release Notes

**Release Date:** 2026-08-21

## Highlights

A tool that supervises its own LLM host can now give that host a real AQE
provider identity — declared as data in `.agentic-qe/llm-config.json` and
selected with `AQE_LLM_PROVIDER` — instead of forking the provider enum or
reporting a vendor that never served the work.

## Added

- External provider registration. A project declares a host under
  `externalProviders` and it becomes a first-class provider identity, usable as
  `defaultProvider`, in `fallbackChain`, in `agentOverrides`, and via
  `AQE_LLM_PROVIDER=<host>`. Declaring a host also enables it.

  ```jsonc
  {
    "externalProviders": {
      "my-host": {
        "kind": "cli",
        "command": ["my-host", "exec"],
        "billingMode": "subscription",
        "models": ["default"]
      }
    }
  }
  ```

  AQE writes the prompt to the host's stdin and reads the completion from
  stdout. Because the declaration is data rather than a module path, one config
  file is picked up identically by the `aqe` CLI and the MCP server — no
  third-party code is imported on the strength of a config file.

- `registerProvider(type, factory)`, exported from `agentic-qe/shared/llm`, for
  consumers that embed AQE in-process rather than spawning it.

- `agentic-qe/shared/llm` is now a package export. The module's own usage
  example had documented this import path while it was never actually exported,
  so library consumers had to reach it through `agentic-qe/shared`.

- `aqe llm providers` lists declared external providers, marked with `*` and a
  footnote so they are never mistaken for providers AQE ships.

## Fixed

- Billing attribution for subscription-billed providers. Any provider reporting
  subscription billing was described as running on the user's *Claude Code*
  subscription — accurate only while the two built-in subscription providers
  were the only ones possible. An external host is now reported as
  `external — <mode> (declared by <source>, not verified by AQE)` in both
  `aqe health` and the startup notice.

## Changed

- The provider type is open to registered identities, while the set AQE ships
  stays closed. Per-provider lookup tables continue to fail the build if a
  built-in provider is added without updating them. `ALL_PROVIDER_TYPES` keeps
  its meaning — "the providers AQE ships" — and its contents are unchanged.

## Upgrade notes

No migration and no behavior change for existing projects. A project that does
not declare `externalProviders` and does not call `registerProvider()` routes
exactly as before; the built-in provider cases are consulted first and a
registration can never shadow one.

Two deliberate limits on declared hosts:

- **Availability is checked without running the host.** AQE resolves the
  declared binary on `PATH` rather than invoking it, since it cannot know what
  invoking an arbitrary host costs. A declaration for a host that is not
  installed on a given machine is valid but unavailable, so config files stay
  portable.
- **Declared hosts do not provide embeddings.** `embed()` raises
  `EMBEDDING_UNSUPPORTED` and the router falls back to a provider that has an
  embeddings endpoint, rather than returning a fabricated vector.

A declared `billingMode` is an assertion AQE records and displays with its
source; it is not verified. Omitting it resolves to `metered-api`, so an
undeclared host is assumed to cost money and to require a budget cap.

See [ADR-127](../implementation/adrs/ADR-127-external-provider-registration.md)
and [the routing guide](../guides/llm-provider-routing.md) for the full
contract.
