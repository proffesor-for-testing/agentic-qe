# v3.14.5 Release Notes

**Release Date:** 2026-09-29

## Highlights

Agentic QE 3.14.5 makes results trustworthy for scripts and CI. Failed commands
now exit non-zero, `aqe platform setup` works again, and Codex setup through a
globally installed `aqe` installs its hooks and skills. The audit chain stays
valid when several AQE processes share a store or when stores are merged, and
the pattern search index binds when an embedder is configured. The CLI is also
much quieter, and plugins now resolve by npm SemVer. Ten of the issues fixed
here were reported by [@pacphi](https://github.com/pacphi), with precise
reproduction scripts. Most of the fixes were contributed by
[@rudycelekli](https://github.com/rudycelekli).

## Exit codes you can trust

- `platform verify`, `plugin install` / `remove` / `info`, invalid hook
  provenance, and any command whose automatic initialization fails now exit 1
  instead of 0.
- `aqe task submit --domain` and MCP `task_submit` reject unknown domains.
- `aqe task submit` without `--wait` now exits 1 with guidance. CLI-submitted
  tasks only ran inside that process, so a detached submit was silently lost.

## Platform and Codex setup

- `aqe platform setup <platform>` works again for all eight platforms
  (Copilot, Cursor, Cline, Kilo Code, Roo Code, Codex, Windsurf, Continue.dev).
- `aqe init --with-codex` installs the Codex hooks and QE skills whether `aqe`
  runs from a global install, a project-local install, or `npx`, and warns when
  packaged assets cannot be found.
- `--codex-guidance full` is applied to an existing `AGENTS.md`, and switching
  guidance modes leaves your own text byte-for-byte unchanged.

## Audit chain and store merges

- Concurrent appends from an MCP server and hooks no longer fork the audit
  chain, so `aqe audit verify --chain audit` stays valid.
- `brain import` records one `BRAIN_IMPORT` audit entry instead of copying
  the source store's audit rows, so the target chain still verifies after a
  merge.

## Learning and project stores

- With an embedder endpoint configured, the pattern search index and
  `brain.rvf` bind in every process. The provenance guard still refuses when no
  embedder or a mismatched embedder is configured.
- `RUVECTOR_USE_*` environment overrides now take effect. Any value other than
  `true` turns that feature off.
- Running `aqe`, the hook runner or the MCP server from a subfolder uses the
  project's root store instead of creating a new one. A stray `~/.agentic-qe`
  no longer claims non-git folders under your home directory.

## Quieter CLI

- Internal startup diagnostics are filtered by `AQE_LOG_LEVEL` / `LOG_LEVEL`
  (default `warn`) and always go to stderr, so stdout carries only command
  output.
- `aqe memory list|get|search|store|delete|usage` open the project store
  directly instead of starting the whole fleet: about 99 lines of startup
  logging per run drop to none, and the commands are faster.
- A command's own `--verbose` flag still shows its detail, and
  `AQE_LOG_LEVEL=debug` shows everything.

## Plugins

- Plugin versions and dependency ranges follow npm SemVer. The newest
  compatible cached version is chosen, and `minAqeVersion` and dependency
  ranges are enforced at install and startup.
- A rejected plugin is reported by name without stopping independent plugins
  from loading, including plugins cached by earlier releases with values that
  are now invalid.

## Security

- Patched a high-severity undici advisory in the vendored Ruflo skill tree.
  The published package was not affected.

## Upgrade notes

- Scripts that ran `aqe task submit` without `--wait` must add `--wait` (or use
  the MCP server). Those submissions never ran before, either.
- In a project with a `.codex/` folder, `aqe init --auto` now adds AQE's
  guidance block to an existing `AGENTS.md`. Use `--codex-guidance none` to opt
  out.
- Git submodules and worktrees inside a repository now get their own
  `.agentic-qe` store. Set `AQE_PROJECT_ROOT` to share the parent's store.
- If you set `RUVECTOR_USE_*` variables, they now apply. Check them before
  upgrading.
- The CLI now reads the generic `LOG_LEVEL` variable. If another tool sets it
  in your environment, `aqe`'s verbosity follows it; set `AQE_LOG_LEVEL` to
  override. Startup diagnostics that used to appear on stdout are now on
  stderr.
- Plugins with a noncanonical version (for example `01.0.0`), a `latest`
  dependency range, or an invalid `minAqeVersion` are now rejected, with a
  warning naming the plugin.
