# hive-mind-init

Initialize the Hive Mind collective intelligence system.

## Usage
```bash
npx ruflo@3.76.0 hive-mind init [options]
```

## Options
- `--force` - Force reinitialize
- `--config <file>` - Configuration file

## Examples
```bash
npx ruflo@3.76.0 hive-mind init
npx ruflo@3.76.0 hive-mind init --force
```
